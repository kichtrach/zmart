# Item Code – V241

Item Code is a unique permanent product identifier, separate from SKU and barcode.

- Format used in demo data: `ITM-000001`
- Add Product: required Item Code field with Auto Generate and manual entry.
- Product list: Item Code column for every product.
- Inventory / Add Stock: Item Code is searchable, visible, and editable while entering stock items.
- Item Code should remain unchanged for the lifetime of a product and be used as the primary internal reference across inventory, purchase and billing.
