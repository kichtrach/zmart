# Sidebar component

Reusable ZMart sidebar component.

- `js/sidebar.js` renders navigation and handles active/open state, routing, desktop collapse, and mobile overlay.
- `css/sidebar.css` owns the sidebar layout and responsive styling.
- `icons/sidebar-icons.css` is the isolated icon layer. Font Awesome is used for icons.
- Warehouse Management links are routed to the implemented Warehouse pages.
